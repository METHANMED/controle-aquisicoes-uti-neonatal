# Acessos e cotações de fornecedores

O administrador continua sendo o responsável global pelo sistema. Cada pessoa autenticada recebe um perfil — **Gerenciamento**, **Acompanhamento** ou **Fornecedor** — e pode ter permissões individuais ajustadas pelo administrador.

| Permissão | Finalidade |
|---|---|
| Ver painel | Acessar os indicadores consolidados. |
| Ver itens | Consultar a relação de equipamentos. |
| Editar itens | Incluir e alterar dados cadastrais dos equipamentos. |
| Ver etapas | Consultar o fluxo de aquisição até instalação. |
| Editar etapas | Atualizar status, datas e observações. |
| Ver notas fiscais | Consultar links de documentos fiscais. |
| Gerenciar notas fiscais | Inserir ou alterar links de documentos fiscais. |
| Ver valores do orçamento | Consultar valores unitários e totais do orçamento-base. |
| Ver cotações de fornecedores | Comparar todas as propostas recebidas. |
| Enviar cotações | Informar ou atualizar valores próprios como fornecedor. |

Por padrão, **Gerenciamento** possui todas as permissões; **Acompanhamento** consulta painel, itens, etapas e notas fiscais sem valores; **Fornecedor** consulta os itens e altera somente as próprias cotações. Uma cotação inclui valor unitário, marca, modelo, prazo em dias, observações e situação de rascunho ou enviada. **Os valores do orçamento-base são exclusivos do perfil Gerenciamento e não podem ser delegados.** Fornecedores não recebem valores do orçamento-base nem cotações de outras empresas.
